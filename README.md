## 1. 운영체제의 역할과 실행 모드

운영체제는 CPU, 메모리, 저장장치 등의 자원을 관리하고 프로그램에 실행 환경을 제공합니다.
프로세스 스케줄링, 메모리 관리, 파일 관리, 장치 접근 및 보호가 대표적인 기능입니다.

| 구분 | 의미 |
| --- | --- |
| 사용자 모드 | 일반 응용 프로그램이 실행되는 제한된 권한의 모드 |
| 커널 모드 | 커널이 자원 관리와 특권 작업을 수행하는 모드 |
| 시스템 콜 | 사용자 프로그램이 커널 서비스를 요청하는 인터페이스 |

사용자 프로그램이 시스템 콜을 호출하면 제어가 커널로 넘어갑니다. 이때 모드가 바뀌더라도 반드시 다른 프로세스로 전환되는 것은 아닙니다.
